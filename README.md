# Конструктор резюме и портфолио

Веб-приложение на Next.js: форма с данными кандидата, генерация текстов резюме через **Google Gemini**, три шаблона оформления, светлая/тёмная тема и акцентные цвета, экспорт в PDF.

## Требования

- Node.js 18+
- API-ключ [Google AI Studio](https://aistudio.google.com/apikey)

## Установка

```bash
npm install
cp .env.example .env.local
```

В `.env.local` укажите ключ **Google AI Studio** (строка вида `AIzaSy…`, не OAuth и не Vertex):

```env
GEMINI_API_KEY=AIzaSy...
```

Создать ключ: [aistudio.google.com/apikey](https://aistudio.google.com/apikey).  
Если в проекте есть файл `.env` со старым ключом — перенесите правильный ключ в `.env.local` (Next.js в dev читает оба; приоритет у `.env.local`).

**Не коммитьте** файл `.env.local` в репозиторий.

## Запуск

```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

При доступе по IP в локальной сети (например `http://192.168.x.x:3000`) Next.js должен разрешать HMR: локальные IPv4 подставляются в `allowedDevOrigins` автоматически. Если IP другой, задайте `ALLOWED_DEV_ORIGINS=ваш.ip` в `.env.local` и перезапустите `npm run dev`.

## Возможности

- Фото, имя, должность, дата рождения, контакты
- Опыт, навыки, образование, языки
- Кнопка «Сгенерировать с ИИ» — краткое описание, сильные стороны и улучшенные формулировки опыта (фото на сервер не отправляется)
- Шаблоны: классика, с боковой панелью, портфолио
- Светлая и тёмная тема, 6 акцентных палитр
- Скачивание PDF
- Черновик сохраняется в `localStorage` браузера

## Лимиты Gemini

Генерация зависит от квот и тарифа Google AI. При ошибке 502 проверьте ключ и лимиты в консоли Google.

## Сборка

```bash
npm run build
npm start
```
